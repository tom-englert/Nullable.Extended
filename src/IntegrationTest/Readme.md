# Integration Test

This repository contains a tests project with simple code to manually 
test the current build of the analyzer and the visual studio extension. 

To test the current build of the analyzer, build the analyzer solution first.

Delete the .\packages cache folder to ensure that the analyzer is loaded from the build output folder and not from the nuget cache.

Then, open the tests project in Visual Studio and build it. The analyzer should be loaded and you should see any warnings or errors generated by the analyzer in the Error List window.
